= Portanforderungen für NetApp Data Migrator
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Sie müssen sicherstellen, dass bestimmte TCP-Ports geöffnet sind, um die Kommunikation zwischen den virtuellen Maschinen (VMs) der Steuerungsebene und den Worker-VMs in NetApp Data Migrator zu ermöglichen.



[[control-plane-ports]]
== Steuerungsebenen-Ports

[cols="1,1,1,1a"]
|===
| Service | TCP-Port | Aus | Zu 


| Temporal | 7233 oder 7234, 8080 | Mitarbeiter und Clients (Browser oder externe Clients)  a| 
Steuerungsebene



| Redis | 6379 | Mitarbeiter und Clients (Browser oder externe Clients)  a| 
Steuerungsebene



| NDM Anwendung | 443 | Mitarbeiter und Clients (Browser oder externe Clients)  a| 
Steuerungsebene



| Grafana | 3000 | Browser  a| 
Steuerungsebene



| Isilon Management Konsole | 443, 8080 | Steuerungsebene  a| 
Isilon Management Konsole



| Ausgehend an Speicher | 2049 | Steuerungsebene  a| 
NFS-Server

*Hinweis*: Geben Sie TCP- oder UDP-Port 111 an, wenn Sie den Portmapper-Dienst für Remote Procedure Calls benötigen.



| Ausgehend an Speicher | 445 | Steuerungsebene  a| 
SMB-Server

|===


[[worker-ports]]
== Worker-Ports

[cols="1,1,1,1a"]
|===
| Service | TCP-Port | Aus | Zu 


| Ausgehend an Speicher | 2049 | Worker  a| 
NFS-Server

*Hinweis*: Geben Sie TCP- oder UDP-Port 111 an, wenn Sie den Portmapper-Dienst für Remote Procedure Calls benötigen.



| Ausgehend an Speicher | 445 | Worker  a| 
SMB-Server

|===
